『一九〇〇年前後のベルリンの幼年時代』刊行記念サイト
最終版用テスト版 — 2026年10月9日

【開き方】
ZIPをすべて展開し、site/index.html をブラウザで開いてください。
インストールやビルドは不要です。画像の拡大表示はローカルでも動作します。
ウェブフォントはオンライン時に読み込まれ、オフラインでは端末の代替書体を使用します。
